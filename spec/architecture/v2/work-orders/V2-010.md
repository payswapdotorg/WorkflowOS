# V2-010 — Reverse Teaching

**Status:** planned · **Dependencies:** `implementation: V2-006, V2-008`
**Wave:** W4 (parallel, no rebase)

## Objective
Allow users to install a workflow they do not understand and have WorkflowOS teach them how to perform the task manually, using the workflow as the executable knowledge source.

## Owns
Reverse-teaching derivation, lesson content, interactive teaching flow, learner practice state, and teaching evidence specific to an installed WorkflowVersion.

## Does not own
Workflow repository/versioning, canonical WorkflowIR, ordinary TeachingSession implementation, computer-agent execution, scheduling/events, optimization, marketplace/economics, or workflow execution semantics.

## Must deliver
- reverse-teaching session bound to an immutable WorkflowVersion;
- extraction of purpose, prerequisites, inputs, steps, decision points and expected outcomes;
- interactive lesson with pause/resume;
- learner practice and evidence;
- clear distinction between workflow execution and human learning;
- uncertainty disclosure where the workflow lacks required teaching context.

## Required regressions
Version pinning, knowledge extraction determinism, missing-information disclosure, learner progress, unsafe instruction handling, evidence separation and execution/teaching distinction.

## Dogfooding
Install a real workflow, invoke reverse teaching, have a real person follow the lesson, then compare the taught task with direct workflow execution.

## Parallelism contract
V2-010 starts after V2-008 is merged and may execute in parallel with V2-009 and V2-011. It must never use a sibling branch as a base. Composition is verified by `IG-004`.
