# DEP-002 — Environment, Secrets, and Configuration Contract

**Status:** PLANNED
**Program:** V2 productionization
**Parallelism:** PARALLEL_AFTER_DEPENDENCIES
**Dependencies:** DEP-001

## Objective
Define and implement the environment/configuration contract for development, staging, preview, and production without leaking secrets or binding semantics to a provider.

## Scope
Environment variable schema, validation, secret requirements, environment isolation, preview restrictions, configuration loading, and safe failure when required production configuration is absent.

## Non-goals
Provisioning provider resources or changing application authorities.

## Required evidence
Deterministic config validation; secret absence/invalid-value tests; staging/production separation proof; no secrets committed; exact-head review.

## Downstream
DEP-003, DEP-004, DEP-005, DEP-006, DEP-007, DEP-008, DEP-009, DEP-010 may depend on this contract as appropriate.

## Completion
Architect merge after exact-head verification.
