# DEP-004 — Redis Coordination Environment

**Status:** PLANNED
**Program:** V2 productionization
**Parallelism:** PARALLEL_AFTER_DEPENDENCIES
**Dependencies:** DEP-002

## Objective
Provision isolated staging and production Redis and connect it only through existing queue/lock/cache abstractions.

## Scope
Upstash configuration, environment isolation, connection validation, queue/lock behavior, bounded retries/timeouts, and proof that Redis outage cannot become application truth.

## Non-goals
Moving authoritative state to Redis or redesigning application coordination semantics.

## Required evidence
Staging integration; failure/discrimination tests; lock/queue behavior under restart; production isolation; exact-head review.

## Downstream
DEP-006, DEP-009, DEP-011.

## Completion
Architect merge after staging proof and exact-head verification.
