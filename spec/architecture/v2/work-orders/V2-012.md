# V2-012 — Collaboration + Marketplace + Economics

**Status:** planned · **Depends:** V2-002, V2-005, V2-006, V2-011

## Objective
Make workflows repository-like collaborative artifacts that can be public/private, shared, forked, reviewed, installed and monetized.

## Must deliver
- repository permissions and visibility;
- collaboration, forks, provenance and version history;
- publish/install lifecycle;
- creator one-time pricing and maintenance subscriptions;
- entitlement and version-access rules;
- refunds/cancellation/maintenance semantics as explicit domain contracts;
- abuse/reporting and trust metadata;
- no payment provider semantics leaking into workflow domain contracts.

## Required regressions
Private visibility isolation, fork provenance, concurrent version publication, entitlement enforcement, subscription cancellation, paid-version pinning and creator maintenance updates.

## Dogfooding
Use a safe test workflow to fork, modify, publish, install and complete a test transaction; verify creator entitlement and version history.
