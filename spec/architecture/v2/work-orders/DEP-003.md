# DEP-003 — Neon PostgreSQL Environments and Migration Control

**Status:** PLANNED
**Program:** V2 productionization
**Parallelism:** PARALLEL_AFTER_DEPENDENCIES
**Dependencies:** DEP-002

## Objective
Provision isolated staging and production PostgreSQL environments and establish authoritative migration execution for the existing application.

## Scope
Neon projects/databases or equivalent configured environments, connection configuration, migration execution process, startup ordering, isolation, backup/restore assumptions, and migration observability.

## Non-goals
Schema redesign, changing PostgreSQL authority, or application data-model changes unrelated to deployment compatibility.

## Required evidence
Isolated staging migration; production migration procedure; race-prevention proof for API/Worker startup; failure recovery procedure; authoritative-state preservation; exact-head review.

## Downstream
DEP-006, DEP-009, DEP-011.

## Completion
Architect merge after staging proof and exact-head verification.
