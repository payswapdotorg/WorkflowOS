# DEP-011 — Production Smoke, Full V2 Dogfooding, and Release Evidence

**Status:** PLANNED
**Program:** V2 productionization
**Parallelism:** FINAL GATE
**Dependencies:** DEP-003, DEP-004, DEP-005, DEP-006, DEP-007, DEP-008, DEP-009, DEP-010

## Objective
Validate the complete production topology as a real user and produce the release evidence package.

## Scope
Authentication/onboarding, workflow browsing/detail, marketplace/install, creation entry and expert authoring where delivered, run/start/recovery/approval controls, scheduling, teaching, version/update, activity/trust, responsive behavior, health/readiness, dependency-failure discrimination, and representative production rollback/smoke checks.

## Required evidence
Deployed revision and URLs; end-to-end browser transcript; screenshots/evidence hashes where appropriate; negative-path checks; production readiness checklist; no critical UX-to-operational mismatch.

## Non-goals
New product functionality discovered during smoke testing. Any new defect must become a governed corrective Work Order rather than an ad-hoc deployment fix.

## Downstream
Unlocks DEP-012 only.

## Completion
Architect review of complete evidence package is required.
