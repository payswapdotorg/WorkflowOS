# IG-001 — Repository ↔ WorkflowIR Integration

**Type:** integration gate · **Inputs:** V2-002, V2-003

## Purpose
Verify that the repository stores and retrieves the exact semantic WorkflowIR carried by an immutable WorkflowVersion without semantic drift.

## Required proof
- repository create/version/install round-trip;
- IR serialize/deserialize round-trip;
- digest equality;
- immutable historical version after later edit;
- installation remains pinned;
- fork preserves provenance but creates independent identity.

## Dogfooding
Create one real workflow, persist/version it, install it, edit it into a new version, and verify both installed versions retain their intended semantics.

## Scope
Integration tests/spec/evidence only. Do not modify sibling implementation surfaces to make them converge. Start from current main after V2-002 and V2-003 merge.
