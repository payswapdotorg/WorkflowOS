# V2-007 — Workflow Compiler

**Status:** planned · **Dependency:** `implementation: V2-003`
**Wave:** W2 (parallel where surfaces allow)

## Objective
Compile authored WorkflowIR into an executable plan while preserving semantics, provenance, capability requirements, policies and version identity.

## Must deliver
- deterministic compilation;
- explicit compile diagnostics;
- capability and placement checks before execution;
- compiled artifact tied to source WorkflowVersion digest;
- safe handling of model-generated plans: generated intent is not proof of execution;
- compiler output is inspectable and reproducible;
- no dependency on an unmerged Run/Evidence implementation.

## Required regressions
Deterministic compilation, source/compiled identity, unsupported capability rejection, placement conflict, invalid graph, policy violation and compiler-version compatibility.

## Dogfooding
Compile one real authored workflow and validate the compiled artifact against the same real task using the compiler's conformance/execution harness. Full integration with durable WorkflowRun/evidence execution is exercised by `IG-003` after V2-005 and V2-008 are merged.

## Parallelism contract
V2-007 may execute in parallel with V2-005 and V2-006 after the W1 contracts are merged. It may consume the **contract** represented by V2-005's Work Order, but must never branch from, rebase onto, or import implementation code from an unmerged V2-005 branch.
