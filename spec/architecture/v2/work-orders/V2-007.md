# V2-007 — Workflow Compiler

**Status:** in-flight · **Dependency:** `implementation: V2-003`
**Wave:** W2 (parallel where surfaces allow)

## Objective
Compile authored WorkflowIR into an executable plan while preserving semantics, provenance, capability requirements, policies and version identity.

## Owns
Compiler inputs/outputs, deterministic compilation, compile diagnostics, compiled-artifact provenance, compatibility, and compiler-specific tests/conformance.

## Does not own
Workflow repository/versioning (V2-002), canonical WorkflowIR semantics (V2-003), Run/evidence persistence (V2-005), teaching, Node/Capability protocol (V2-004), computer-agent execution (V2-008), scheduling/events, optimization, reverse teaching, or marketplace economics.

## Must deliver
- deterministic compilation;
- explicit compile diagnostics;
- capability and placement checks before execution;
- compiled artifact tied to source WorkflowVersion digest;
- safe handling of model-generated plans: generated intent is not proof of execution;
- compiler output is inspectable and reproducible;
- no dependency on an unmerged Run/Evidence implementation.

## Required regressions
Deterministic compilation, source/compiled identity, unsupported capability rejection, placement conflict, invalid graph, policy violation, compiler-version compatibility, and provenance preservation.

## Dogfooding
Compile one real authored workflow and validate the compiled artifact against the same real task using the compiler's conformance/execution harness. Full integration with durable WorkflowRun/evidence execution is exercised by IG-003 after V2-005 and V2-008 are merged.

## Parallelism contract
V2-007 may execute in parallel with V2-005 and V2-006 after the W1 contracts are merged. It may consume only the V2-003 implementation plus frozen W1 contracts; it must never branch from, rebase onto, or import implementation code from an unmerged V2-005 or sibling branch.

## Activation
Activated by the sole architect as part of W2A from stable main `f3fde6f3219157a07a2b759663a25306e7c02b22`. Implementation branch must use that exact base and must not rebase onto a W2A sibling.
