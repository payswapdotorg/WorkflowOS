# IG-003 — Compiled Execution + Runs/Evidence Integration

**Type:** integration gate · **Inputs:** V2-005, V2-007, V2-008

## Purpose
Verify that a compiled WorkflowIR executes through the computer-agent/runtime boundary and produces truthful WorkflowRun/evidence records.

## Required proof
- source WorkflowVersion digest is bound to compiled artifact;
- compiled workflow executes only through declared capabilities and policy;
- run/step/capability evidence correlates correctly;
- model assertions are not treated as proof;
- pause/resume and human takeover preserve run identity;
- recoverable failure does not produce false completion.

## Dogfooding
Run one real authored workflow through compile → execution → evidence inspection, including one controlled failure/takeover case.

## Scope
Integration tests/spec/evidence only. Start from current main after V2-005, V2-007 and V2-008 are merged.
