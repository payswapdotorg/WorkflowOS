# DEP-005 — R2 Object Storage Adapter

**Status:** PLANNED
**Program:** V2 productionization
**Parallelism:** PARALLEL_AFTER_DEPENDENCIES
**Dependencies:** DEP-002

## Objective
Provide production-capable Cloudflare R2 object/artifact storage through the existing storage abstraction without changing storage authority semantics.

## Scope
R2 adapter/configuration, bucket isolation, object key policy, upload/download/delete behavior, retries/timeouts, and migration-safe local-vs-production selection.

## Non-goals
Using R2 as relational state or introducing a second evidence/application database.

## Required evidence
Staging persistence/retrieval; provider failure behavior; object isolation; local development compatibility; exact-head review.

## Downstream
DEP-006, DEP-009, DEP-010, DEP-011.

## Completion
Architect merge after staging proof and exact-head verification.
