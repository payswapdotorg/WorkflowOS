# IG-005 — Marketplace ↔ Self-Hosting Integration

**Type:** integration gate · **Inputs:** V2-012, V2-013

## Purpose
Verify that collaborative/marketplace workflows and first-party WorkflowOS workflows use the same installation, policy, versioning and execution authorities.

## Required proof
- published workflow installation remains version-pinned;
- entitlement does not bypass execution authorization;
- fork provenance survives publication;
- first-party WorkflowOS workflows use the same protocol as third-party workflows;
- self-hosting cannot bypass development governance;
- maintenance updates create explicit version transitions.

## Dogfooding
Use a safe test workflow to fork, publish, install and execute it, then install and execute one first-party WorkflowOS development workflow through the same protocol.

## Scope
Integration tests/spec/evidence only. Start from current main after V2-012 and V2-013 merge.
