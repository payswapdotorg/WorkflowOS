# DEP-008 — Cloudflare DNS, TLS, Edge, and Turnstile

**Status:** PLANNED
**Program:** V2 productionization
**Parallelism:** PARALLEL_AFTER_DEPENDENCIES
**Dependencies:** DEP-002, DEP-006, DEP-007

## Objective
Put the deployed V2 API and frontend behind production DNS/TLS and appropriate edge protections without moving application authority into Cloudflare.

## Scope
DNS records, TLS mode, API/frontend hostnames, origin protection, health routing, Turnstile integration only where an existing sensitive public flow requires it, and environment separation.

## Non-goals
Changing application auth or introducing Cloudflare as an application/identity authority.

## Required evidence
HTTPS end-to-end; origin connectivity; DNS cutover/rollback procedure; Turnstile behavior if enabled; preview isolation; exact-head review.

## Downstream
DEP-011.

## Completion
Architect merge after staging/edge proof and exact-head verification.
