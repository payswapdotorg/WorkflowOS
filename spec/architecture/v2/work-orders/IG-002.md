# IG-002 — WorkflowIR ↔ Capability/Placement Integration

**Type:** integration gate · **Inputs:** V2-003, V2-004

## Purpose
Verify that a platform-neutral WorkflowIR can request capabilities and placement without embedding platform semantics.

## Required proof
- capability requirement matching;
- authorization distinct from capability possession;
- placement/locality/privacy constraints;
- unsupported-platform rejection;
- same semantic workflow represented against multiple eligible node types.

## Dogfooding
Take one real workflow that can run on two supported host classes and verify equivalent workflow meaning with host-specific capability resolution.

## Scope
Integration tests/spec/evidence only. Start from current main after V2-003 and V2-004 merge. Never rebase onto sibling branches.
