# DEP-007 — Vercel Frontend Delivery

**Status:** PLANNED
**Program:** V2 productionization
**Parallelism:** PARALLEL_AFTER_DEPENDENCIES
**Dependencies:** DEP-002

## Objective
Deliver the existing V2 frontend as a production web application with environment-specific API configuration and no production-state access from previews.

## Scope
Vercel project configuration, build/output settings, environment variables, preview isolation, HTTPS, API origin configuration, deployment promotion, and staging validation.

## Non-goals
Frontend redesign, V2 UX semantic changes, or backend authority changes.

## Required evidence
Staging/preview deployment; production build reproducibility; environment separation; authenticated API connectivity; browser smoke; exact-head review.

## Downstream
DEP-011 depends on production frontend and API connectivity; DEP-008 consumes the final frontend/API hostnames.

## Completion
Architect merge after deployment proof and exact-head verification.
