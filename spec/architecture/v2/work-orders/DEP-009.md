# DEP-009 — Deployment CI/CD, Migration Gating, Rollback, and Smoke Verification

**Status:** PLANNED
**Program:** V2 productionization
**Parallelism:** PARALLEL_AFTER_DEPENDENCIES
**Dependencies:** DEP-002, DEP-003, DEP-006

## Objective
Automate build, deterministic verification, migration gating, deployment promotion, rollback, and smoke-test execution through GitHub Actions without creating a second release authority.

## Scope
CI/CD workflow definitions, artifact/build provenance, migration gate, environment promotion rules, rollback procedure, deployment smoke suite, exact revision recording, and failure notification.

## Non-goals
Making GitHub Actions a semantic WorkflowOS authority or changing application release semantics.

## Required evidence
Staging pipeline execution; migration race/failure tests; rollback rehearsal; smoke test against deployed revision; protected production promotion path; exact-head review.

## Downstream
DEP-010 and DEP-011 may consume the pipeline; DEP-012 consumes final deployment evidence.

## Completion
Architect merge after successful staging pipeline and rollback proof.
