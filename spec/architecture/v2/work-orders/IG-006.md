# IG-006 — Cross-Device Execution Attestation Composition

**Type:** integration gate  
**Inputs:** V2-005, V2-008, V2-009, V2-014

## Purpose

Verify that durable WorkflowRuns, computer/device execution, locality-aware placement, and ExecutionAttestations compose into one cross-device execution protocol without duplicate side effects or trust-boundary collapse.

## Required proof

- one Run and WorkflowVersion identity preserved across two nodes;
- step execution on Node A produces a valid ExecutionAttestation;
- Node B independently verifies the attestation before admitting a dependent action;
- freshness/replay protection works across reconnect/retry;
- causal parent binding is enforced;
- duplicate handoff/event delivery converges without duplicate side effects;
- capability and authorization remain separate;
- insufficient node trust/assurance produces an explicit ineligible/rejected result;
- evidence and attestation references reconstruct the execution history.

## Dogfooding

Run one safe cross-device workflow using two real supported hosts. Execute a first step on host A, transfer the run, verify its attestation on host B, execute a dependent step, disconnect/reconnect or replay one message, and verify the resulting Run/evidence/proof graph remains correct and side-effect-safe.

## Scope

Integration tests, protocol conformance, evidence and dogfooding only. Do not modify sibling internals to force composition. Start from current `main` after every listed input is COMPLETE.

## Completion

IG-006 cannot be marked COMPLETE until all listed inputs are actually merged and finalized, its deterministic and real-system proofs pass, cross-feature dogfooding evidence is persisted, and the sole architect accepts the gate.
